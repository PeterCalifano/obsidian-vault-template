# Open actions

Every open checkbox in the vault, pulled in automatically by the **Tasks**
plugin. Nothing here is edited directly: tick items off in the note where they
live and they drop off this list. See [[Action items]] for the convention.

## Overdue

```tasks
not done
due before today
group by filename
```

## Due soon

```tasks
not done
due after today
sort by due
group by filename
```

## No due date

```tasks
not done
no due date
group by filename
```

## By project or tag

```tasks
not done
sort by due
group by tags
```
