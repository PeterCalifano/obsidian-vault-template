# Getting started

Use this checklist when creating a new vault from the template.

- [ ] Rename the repository and vault for the new subject.
- [ ] Decide whether the vault is personal, collaborative, or public.
- [ ] Review the folders and remove anything unnecessary.
- [ ] Add the first project, reference, or note using a template.
- [ ] Open [[Open actions]] and confirm the Tasks plugin is working.
- [ ] Test a Git pull and commit-and-sync before adding important content.
- [ ] Configure any optional plugin accounts or command-line tools locally.
- [ ] Check that no credentials or private material are tracked.

## First note

For an unstructured thought, use `Templates/Note.md`. For recurring work,
start with a project note and link meetings, decisions, experiments, and
references back to it.

## First action

Add a checkbox to any note:

```markdown
- [ ] Try the new workflow 📅 2026-09-05 #project/example
```

Then open [[Open actions]]. The item should appear in the appropriate section.
