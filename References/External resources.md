# External resources

Keep large or separately managed files outside the Markdown repository and
link them from the relevant note. Typical examples include documents,
spreadsheets, presentations, datasets, videos, archives, and generated
deliverables.

## Linking rule

The note should explain why a resource matters and link to the external source.
The external source does not need to link back to the vault.

```markdown
## External resources

- [Project folder](https://example.com/)
- [Results spreadsheet](https://example.com/)
```

Use the storage system appropriate to the project. Check its sharing and
access permissions before adding a link to a collaborative vault.
